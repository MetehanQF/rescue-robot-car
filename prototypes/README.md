# Prototypes

One directory per prototype. Each holds the record of what was built, what was
tested, and what broke — the failures are the point, since they are the
requirements for the next iteration.

Firmware and hardware documentation live in the top-level `firmware/` and
`hardware/` directories rather than being duplicated per prototype; this folder
is the narrative.
