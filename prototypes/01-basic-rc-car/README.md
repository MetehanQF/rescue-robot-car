# Prototype 01 - Basic RC Rescue Car

This is the first prototype of the rescue robot project.

## Purpose
The purpose of this prototype was to test basic wireless control, motor control, power distribution and mechanical structure.

## Main Components
- STM32F4 Discovery
- ESP32 controller
- BTS7960B motor drivers
- Two DC motors
- 3S2P 18650 battery pack
- LM2596 buck converter
- HC-SR04 distance sensor

## Tested Features
- Wireless control with ESP32
- UART communication between ESP32 and STM32
- PWM motor control
- Basic movement tests
- Power distribution test

## Problems Observed
- Motor noise affected the system
- Cable management was not good enough
- Mechanical structure was not modular
- Power system needed improvement
